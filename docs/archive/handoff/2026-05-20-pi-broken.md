# Pi Coding Agent is Permanently Broken (Python 3.13+)

**Date:** 2026-05-20
**Affected tool:** `pi` (Python Pi Coding Agent, `pip install pi`)
**Root cause:** Python 3.12+ removed `imp.find_module()` — the `pi` package uses it

## The Error

```
File "C:\Program Files\Python313\Lib\site-packages\pi\cli.py", line 12
    imp_loader = imp_importer.find_module(fullname)
                 ^^^^^^^^^^^^^^^^^^^^^^^^
AttributeError: 'FileFinder' object has no attribute 'find_module'
```

## Why This Happened

The `imp` module has been deprecated since Python 3.4 and **removed in Python 3.12**:
- `imp.find_module()` was replaced by `importlib.util.find_spec()` in Python 3.4
- Python 3.13 (which you have installed at `C:\Program Files\Python313`) completely removed `find_module`

The `pi` package on PyPI (last updated ~2017) uses this dead API. There is no fix short of forking and rewriting the package — which we will not do because:
1. It is unmaintained (last release years ago)
2. We are building our own tools from scratch (NEXUS OS philosophy)
3. There are better alternatives
