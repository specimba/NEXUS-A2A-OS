- Why NEXUS cares: CVE-2026-42271 + CVE-2026-48710 is the first *chained, actively-exploited-in-the-wild, CVSS 10.0, unauthenticated* RCE in a production LLM gateway proxy, and the chain's two-CVE composition (one in the gateway's MCP test endpoint, one in the gateway's web framework) is the new canonical shape for LLM-gateway RCE that NEXUS's defense-in-depth must catch at the *class* level, not at any single CVE. The architecture: **CVE-2026-42271** is a command-injection in LiteLLM's two MCP server test endpoints (`POST /mcp-rest/test/connection` and `POST /mcp-rest/test/tools/list`) that accept a full server configuration (command, args, env) and spawn the supplied input as a subprocess on the host; the endpoints were gated only by a proxy API key and had no role-based access control. **CVE-2026-48710** is a Starlette "BadHost" Host-header validation bypass affecting Starlette ≤ 1.0.0 that, when chained with CVE-2026-42271, lets an attacker manipulate the HTTP Host header to bypass the API key check entirely and trigger the MCP test endpoints to spawn arbitrary commands without authentication. The end-state is unauthenticated RCE on the LiteLLM host with the proxy process's privileges, which means the attacker gets the proxy's *stored* OpenAI / Anthropic / Azure API keys (every customer's outbound LLM credentials), the proxy's environment variables (every customer's secret-bearing config), and the proxy's reach into downstream AI infrastructure. Three concrete NEXUS maps. **(a) The MCP test-endpoint command-injection class ↔ NEXUS's `src/nexus_os/security/owasp_llm_patterns.json` (per 2026-06-08-00 #1) and the existing `NexusOwaspClassDetector` in `src/nexus_os/security/sanitizer.py`** — the pattern table seeded at 2026-06-08-00 #1 has the Semantic Kernel RCE class, the Codex auth-theft class, the Miasma Phase 2 class, and the jqwik/LucidShark dependency-prose class. The signature is class-shaped, not CVE-shaped, so a future LiteLLM patch bypass (the same shape as the Flowise CVE-2026-40933 patch-bypass from 2026-06-08-12 #1) is caught by the same entry. **(b) The Host-header auth-bypass class ↔ NEXUS's `src/nexus_os/mcp/server.py` NexusGovernanceMCP and the Flowise stdio kill-switch from 2026-06-08-12 #1** — NEXUS's NexusGovernanceMCP is a Bun + Hono server (per AGENTS.md / 2026-06-08-12 #1), not Starlette, so the specific Starlette BadHost bypass does not apply, but the *class* (HTTP framework that derives authentication from a mutable client-supplied header) is generic. The three new branches. **(a) `.pth` startup-hook pattern (refined from 2026-06-08-18 #2)** — a malicious wheel bundles a `*-setup.pth` file alongside `_index.js`; the hook fires during Python startup, silently downloads the Bun JavaScript runtime, and executes the obfuscated stealer.
