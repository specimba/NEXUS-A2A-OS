## Findings (NEXUS-relevant only)

### 1. CVE-2026-40933 — Flowise MCP stdio Remote Code Execution (9.9 severity)
- Source: https://www.csoonline.com/article/4179309/flowises-mcp-implementation-can-run-ghost-commands.html
- Why NEXUS cares: NEXUS ships `src/nexus_os/mcp/server.py` (NexusGovernanceMCP) as its MCP server implementation. This CVE reveals that stdio MCP transport can be weaponized for RCE via ghost commands — attackers inject tool calls that bypass Flowise's allowlist and achieve host-level code execution without authentication. The vulnerability pattern (stdio transport, insufficient input sanitization, tool allowlist bypass) is directly applicable to any stdio-based MCP server, including NEXUS's own MCP server. NEXUS's `src/nexus_os/security/sanitizer.py` currently screens terminal output for prompt injection but does not cover stdio MCP transport-level tool invocation boundaries.
- Suggested follow-up: Audit `src/nexus_os/mcp/server.py` for transport-level tool call validation — confirm that all incoming MCP tool calls go through a allowlist/validation gate before execution, and that stdio transport input cannot inject ghost commands through the JSON-RPC layer.

### 2. Litellm Adaptive Router — Crash on Reload After Persisted State Corruption (PR #29398)
- Source: https://github.com/BerriAI/litellm/pull/29398
- Why NEXUS cares: NEXUS's ModelRelay v6 (localhost:8040) implements adaptive intent-tier routing with Thompson sampling over provider tiers. This PR fixes a crash where `load_state_from_db` overwrote the cold-start prior with raw persisted deltas (increment values) instead of merging them onto the prior — causing `gammavariate: alpha and beta must be > 0.0` on reload. The result was HTTP 500 on every request after a proxy restart. NEXUS's ModelRelay relay layer (`src/nexus_os/gmr/` or relay routes) has equivalent restart/failover paths; if bandit state is persisted across restarts, the same class of crash could occur.
- Suggested follow-up: Check whether NEXUS's ModelRelay v6 persists routing state to any backing store across restarts. If so, verify that the cold-start prior is merged with persisted deltas (not overwritten) on load — mirroring the fix in PR #29398.
